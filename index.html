1. Executive Summary & Verdict

In October 2026, the Security Operations Center (SOC) identified critical security events within the corporate cloud environment: unauthenticated inbound web shell execution on the DMZ perimeter and subsequent termination of Windows Defender real-time monitoring on an internal corporate workstation.

🔴 Fact of System Compromise: PROVEN
The threat actor successfully achieved Remote Code Execution (RCE) on web_server (10.0.10.5) via an unvalidated file upload vulnerability, pivoted into the internal client subnet via Remote Desktop Protocol (RDP) using compromised credentials, disabled endpoint antivirus defenses, and spawned unauthorized command-and-control (C2) payloads.
🟢 Fact of Data Exfiltration: NOT CONFIRMED / PREVENTED
Deep forensic analysis of Wazuh File Integrity Monitoring (FIM), Sysmon telemetry, network socket telemetry, and database logs confirms that the threat was successfully isolated before data archiving, staging, or external exfiltration of sensitive business databases occurred.

6. Root Cause Analysis & Hardening Recommendations

Root Causes:

• DMZ Isolation Failure: Web server in DMZ possessed unrestricted routing into internal workstation subnets.
• Absence of Tamper Protection: Windows Defender lacked GPO-enforced Tamper Protection, allowing administrative scripts to terminate protection.
• Shared Administrative Credentials: Identical passwords used across Linux web server and Windows endpoints.

Remediation Roadmap:

Priority Scope Action Item
P1: Immediate Network / Host Isolate compromised hosts, terminate C2 sockets, purge malicious artifacts, and rotate all administrative credentials.
P2: Short-Term Active Directory Enforce Tamper Protection via GPO; deploy Microsoft LAPS across all endpoints to eliminate local password reuse.
P2: Short-Term Application Harden web server upload directories (disable script execution) and deploy AppLocker/WDAC blocking binaries in Temp folders.
P3: Strategic Architecture Implement micro-segmentation at router vy prohibiting DMZ-to-Internal connections; enable Wazuh Active Response for automated isolation.
